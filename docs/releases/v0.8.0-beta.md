# ES.Topo 0.8.0-beta

## Français

**ES.Topo** garde l'historique de la topologie de vos clusters Elasticsearch (7.17 à 9.x) et permet de l'explorer dans le temps : où étaient les shards à une date donnée, quels nœuds sont partis et avec quelles copies, ce qui a bougé entre deux dates. Un seul binaire, sans dépendance, collecte en lecture seule et sert une interface web embarquée.

C'est la **première version publique**.

### Points forts

- Collecte adaptative en lecture seule : sonde légère toutes les 5 minutes, capture complète quand quelque chose change.
- État d'un cluster à n'importe quelle date : vue physique (zone, tier, machine, nœud) et vue logique (familles d'indices × nœuds).
- Diff entre deux dates, chemin parcouru, pertes de copies, journal d'événements, flux de déplacements, contraintes d'allocation.
- Recherche, exports CSV, JSON et XLSX, interface en français et en anglais.
- Authentification locale ou LDAP (OpenLDAP), instance standby à promotion manuelle, `/healthz` et `/metrics`.
- Simulateur `essim` pour essayer le produit sans cluster réel.

### Binaires

| Fichier | Plateforme |
|---|---|
| `estopo-linux-amd64`, `essim-linux-amd64` | Linux x86-64 (production) |
| `estopo-windows-amd64.exe`, `essim-windows-amd64.exe` | Windows x64 (essai, développement) |
| `estopo-macos-arm64`, `essim-macos-arm64` | macOS arm64, Apple Silicon (essai, développement) |
| `SHA256SUMS` | sommes de contrôle des binaires |
| `LICENSE`, `THIRD_PARTY_NOTICES.md` | licence AGPL-3.0 et licences des composants inclus |

Vérifiez votre téléchargement, dans le dossier qui contient le binaire et `SHA256SUMS` :

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

Les binaires sont statiques et ne demandent aucune installation. Ils ne sont pas signés : Windows et macOS peuvent afficher un avertissement au premier lancement.

### Statut bêta et limites connues

Le produit a été testé contre de vrais clusters Elasticsearch 7.17.29, 8.19.22 et 9.5.4 de test et sur des données simulées, pas encore en production à grande échelle. À savoir avant de l'utiliser :

- sans réglage, il écoute sur `127.0.0.1:8080` **sans authentification** : activez-la avant de l'exposer ;
- pas de bascule automatique en haute disponibilité ;
- seul OpenLDAP est testé comme annuaire ;
- pas de retour à une version antérieure après une mise à jour ;
- le format des données et l'API peuvent changer avant la version 1.0.

La liste complète est dans le journal des versions.

## English

**ES.Topo** keeps the history of the topology of your Elasticsearch clusters (7.17 to 9.x) and lets you explore it over time: where the shards were at a given date, which nodes left and with which copies, what moved between two dates. A single binary with no dependencies collects read-only and serves an embedded web interface.

This is the **first public release**.

### Highlights

- Adaptive read-only collection: light probe every 5 minutes, full capture when something changes.
- State of a cluster at any date: physical view (zone, tier, machine, node) and logical view (index families × nodes).
- Diff between two dates, path taken, lost copies, event journal, relocation flows, allocation constraints.
- Search, CSV, JSON and XLSX exports, interface in French and English.
- Local or LDAP (OpenLDAP) authentication, standby instance with manual promotion, `/healthz` and `/metrics`.
- `essim` simulator to try the product without a real cluster.

### Binaries

| File | Platform |
|---|---|
| `estopo-linux-amd64`, `essim-linux-amd64` | Linux x86-64 (production) |
| `estopo-windows-amd64.exe`, `essim-windows-amd64.exe` | Windows x64 (trial, development) |
| `estopo-macos-arm64`, `essim-macos-arm64` | macOS arm64, Apple Silicon (trial, development) |
| `SHA256SUMS` | checksums of the binaries |
| `LICENSE`, `THIRD_PARTY_NOTICES.md` | AGPL-3.0 licence and licences of the included components |

Verify your download, in the directory holding the binary and `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

The binaries are static and need no installation. They are not signed: Windows and macOS may show a warning at the first launch.

### Beta status and known limits

The product has been tested against real test clusters running Elasticsearch 7.17.29, 8.19.22 and 9.5.4 and on simulated data, not yet in production at scale. Good to know before using it:

- without any setting, it listens on `127.0.0.1:8080` **without authentication**: enable it before exposing the service;
- no automatic failover with high availability;
- only OpenLDAP is tested as a directory;
- no going back to an earlier version after an upgrade;
- the data format and the API may change before version 1.0.

The full list is in the changelog.
